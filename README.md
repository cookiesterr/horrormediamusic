# horrormediamusic
music that can be used in horror games,movies,etc.

I made a website through which you can listen to the songs i made on strudel.cc (REPL) which is a live javascript based environment.

Live Demo: https://cookiesterr.github.io/horrormediamusic/

TRACKLIST:

1. Ambience — Dark, atmospheric background soundscape.
   
3. Chase Song — Fast-paced, high-tension intensity track.
   
5. Eerie Song — Suspenseful and unsettling melody.
   
7. Menu SonG — Low-key, haunting menu theme.

Tech Stack:

Frontend: HTML5, CSS3, JavaScript 
  
Audio Composition: [Strudel Livecoding REPL](https://strudel.cc/)
  
Hosting: GitHub Pages
